📋 REQUIREMENTS:
   • Node.js (v14 or higher)
   • npm (comes with Node.js)
   • Web browser (Chrome, Firefox, Safari, Edge)

🚀 INSTALLATION STEPS:

   Step 1: Install Node.js
   ─────────────────────────────────────────────────────────────
   If you don't have Node.js installed:
   1. Go to: https://nodejs.org/
   2. Download LTS version
   3. Install with default settings
   4. Verify installation:
      Open terminal/cmd and type: node --version


   Step 2: Install Dependencies
   ─────────────────────────────────────────────────────────────
   Open terminal/command prompt in this folder and run:
   
   npm install
   
   Wait for installation to complete (1-2 minutes)


   Step 3: Start the Server
   ─────────────────────────────────────────────────────────────
   Run this command:
   
   npm start
   
   You should see:
   ✅ EditIQ Admin Panel Server running on http://localhost:3000


   Step 4: Open in Browser
   ─────────────────────────────────────────────────────────────
   Open your web browser and go to:
   
   http://localhost:3000/login


   Step 5: Login
   ─────────────────────────────────────────────────────────────
   Use these credentials:
   
   Username: Editiq.admin
   Password: Editiq.Password


🎉 DONE! You're now in the Admin Dashboard!

🆘 TROUBLESHOOTING:

   Problem: "npm: command not found"
   Solution: Install Node.js from https://nodejs.org/

   Problem: "Port 3000 already in use"
   Solution: Change PORT in .env file to 3001

   Problem: "Cannot login"
   Solution: Check username and password are correct

   Problem: Server won't start
   Solution: Delete node_modules folder, run npm install again
